# Support

Use [GitHub Issues](https://github.com/panchalvimaldev/git-account-switcher/issues) for bug reports and feature requests.

When reporting a problem, include:

- VS Code version and operating system
- Git and Git Credential Manager versions
- Remote transport (HTTPS or SSH) and hosting provider
- Reproduction steps
- Relevant output from **View → Output → Git Account Switcher**, after checking it for personal information

Never include passwords, personal access tokens, OAuth tokens, or private SSH keys.
